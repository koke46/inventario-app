Datos que tratamos y para qué

  • Dirección IP — cuando un usuario activa la prueba gratuita de la aplicación, se registra su IP para controlar el período de demo y evitar activaciones múltiples. Base legal: interés legítimo (art. 6.1.f RGPD).
  • Fecha y hora de acceso — se registra la última vez que una licencia activa accede al servicio para gestión interna. Base legal: ejecución del contrato (art. 6.1.b RGPD).
  • Datos del negocio introducidos por el cliente — productos, ventas, usuarios y configuración. Estos datos se almacenan en el propio navegador del cliente (localStorage) y, si el cliente usa la función de sincronización, en servidores seguros (Supabase). El titular no accede a estos datos salvo requerimiento del cliente para soporte técnico.

¿Cuánto tiempo conservamos los datos?

  • Direcciones IP del demo: hasta 60 días desde la activación, o hasta que el usuario solicite su eliminación.
  • Fechas de acceso de licencias: mientras la licencia esté activa y hasta 1 año después de su cancelación.
  • Datos del negocio en la nube: hasta que el cliente solicite su eliminación o durante 1 año tras la cancelación del servicio.

¿Con quién compartimos los datos?

Los datos se almacenan en Supabase (proveedor de base de datos en la nube con servidores en la UE). No cedemos datos a terceros salvo obligación legal. Supabase actúa como encargado del tratamiento con las garantías adecuadas conforme al RGPD.

Transferencias internacionales

Supabase puede almacenar datos en servidores ubicados en la Unión Europea. En caso de transferencias fuera del EEE, Supabase ofrece las garantías adecuadas mediante cláusulas contractuales tipo aprobadas por la Comisión Europea.

3. Política de Cookies

Esta web no utiliza cookies propias ni de terceros para rastrear usuarios ni con fines publicitarios.

La aplicación utiliza almacenamiento local del navegador (localStorage) para guardar los datos del negocio del cliente en su propio dispositivo. Este mecanismo no es una cookie y no transmite datos a ningún servidor de forma automática.

No se emplean cookies analíticas, de marketing ni de seguimiento de ningún tipo.
